# Security

This file is the default security policy for kjiwa's public repositories that
do not define their own. See each repo's own `SECURITY.md` if it has one; it
takes precedence over this one.

## Reporting a vulnerability

Please use the affected repository's Security tab > Report a vulnerability
([GitHub's private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability))
rather than opening a public issue. If that option isn't available on the
repository, email kamil.jiwa@gmail.com instead.
